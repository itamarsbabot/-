# המורה של ליה – מתמטיקה ופיזיקה, כיתה י׳, 5 יח״ל

אפליקציית מורה פרטי לאייפד ולאייפון. המורה מבוסס על Claude.

## מה יש באפליקציה

| מסך | מה עושים בו |
|---|---|
| 🎓 שיעור פרטי | לומדים נושא בשיטה סוקרטית: המורה שואל שאלות ומוביל להבנה, לא רק מכתיב תשובות |
| 📒 עזרה בשיעורי בית | מצלמים את הדף, כותבים בעט או מקלידים. כפתורים: רמז / הצעד הבא / בדיקת הפתרון / פתרון מלא |
| 🎯 תרגול | שאלות ברמת בגרות לפי נושא, בחמש דרגות קושי. הקושי עולה ויורד לפי ההצלחה, עם ציון ומשוב מיידי |
| ⏱️ בוחן | 5 שאלות, 20 דקות, עם שעון, ציון ומשוב לכל שאלה |
| 📝 מבחן בגרות | 4 שאלות עם סעיפים בסגנון שאלון 5 יח״ל, 90 דקות, בדיקה כמו של בודק בגרות (כולל ניקוד חלקי) |
| 📈 התקדמות | ממוצע לכל נושא, היסטוריית מבחנים ונושאים לחיזוק (הם מסומנים גם במסך בחירת הנושאים) |

**כתיבה:** מקלדת (עם שורת סימנים: √ ² π ≤ ≠ θ Δ…) ו-**Apple Pencil**: משטח משבצות שמגיב ללחץ העט, עם צבעים, מחק, ביטול וכפתור "עט בלבד" שמונע מכף היד לכתוב. הכתב נשלח למורה כתמונה, והוא קורא אותו.
נוסחאות מוצגות כמו בספר (KaTeX), וכל הממשק בעברית ומימין לשמאל.

## התקנה (פעם אחת, כ-10 דקות)

1. **מפתח API:** נכנסים ל-[console.anthropic.com](https://console.anthropic.com), יוצרים מפתח API ומגדירים מגבלת הוצאה חודשית.
2. **העלאה ל-Netlify (חינם):** ב-[app.netlify.com](https://app.netlify.com) בוחרים *Add new site → Import from GitHub* ובוחרים את ה-repo הזה. ההגדרות כבר נמצאות ב-`netlify.toml`.
3. **משתני סביבה** (ב-Netlify: *Site configuration → Environment variables*):
   - `ANTHROPIC_API_KEY` – המפתח מסעיף 1.
   - `TUTOR_ACCESS_CODE` – קוד שתבחרו (למשל `liya2026`), כדי שרק ליה תוכל להשתמש באתר.
   אחרי שמגדירים אותם עושים Deploy מחדש.
4. **באייפד ובאייפון:** פותחים את כתובת האתר ב-Safari, לוחצים שיתוף ⬆︎ ואז **"הוספה למסך הבית"**. בהגדרות ⚙︎ של האפליקציה מכניסים את קוד הגישה.

## הרצה מקומית (למפתחים)

```bash
npm install
ANTHROPIC_API_KEY=sk-ant-... node server.mjs   # http://localhost:8888
```

## מבנה הקוד

- `public/` – האפליקציה עצמה (HTML/CSS/JS, בלי שלב build). אפשר להתקין אותה כ-PWA.
  - `js/pad.js` – משטח הכתיבה לעט. `js/composer.js` – תיבת התשובה (טקסט, עט ותמונה).
  - `js/views/` – המסכים. `js/store.js` – שמירת ההתקדמות במכשיר.
- `netlify/functions/tutor.mjs` – שרת שמעביר את הבקשות ל-Claude. המפתח נשאר בשרת ולא מגיע למכשיר.
- `netlify/lib/prompts.mjs` – ההנחיות למורה ורשימת הנושאים לפי תוכנית הלימודים. **כאן משנים נושאים, סגנון או רמה.**

## הערות

- ההתקדמות נשמרת רק במכשיר שעליו עובדים (אפשר לייצא גיבוי מההגדרות).
- המורה משתמש ב-Claude Opus 5.5. העלות תלויה בכמות השימוש: תרגול רגיל עולה בערך כמה סנטים לשאלה, ומבחן מלא עולה יותר.
- כדאי לעדכן ב-`prompts.mjs` את רשימת הנושאים לפי הסילבוס של המורה בבית הספר.
