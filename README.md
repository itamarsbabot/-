# המורה של ליה – מתמטיקה ופיזיקה, כיתה י׳, 5 יח״ל

אפליקציית מורה פרטי לאייפד ולאייפון. המורה מבוסס על Gemini של גוגל (חינם), ואפשר לעבור ל-Claude.

## מה יש באפליקציה

| מסך | מה עושים בו |
|---|---|
| 🎓 שיעור פרטי | לומדים נושא בשיטה סוקרטית: המורה שואל שאלות ומוביל להבנה, לא רק מכתיב תשובות |
| 📒 עזרה בשיעורי בית | מצלמים את הדף, כותבים בעט או מקלידים. כפתורים: רמז / הצעד הבא / בדיקת הפתרון / פתרון מלא |
| 🎯 תרגול | שאלות ברמת בגרות לפי נושא, בחמש דרגות קושי. הקושי עולה ויורד לפי ההצלחה, עם ציון ומשוב מיידי |
| ⏱️ בוחן | 5 שאלות, 20 דקות, עם שעון, ציון ומשוב לכל שאלה |
| 📝 מבחן בגרות | 4 שאלות עם סעיפים בסגנון שאלון 5 יח״ל, 90 דקות, בדיקה כמו של בודק בגרות (כולל ניקוד חלקי) |
| 📈 התקדמות | ממוצע לכל נושא, היסטוריית מבחנים ונושאים לחיזוק (הם מסומנים גם במסך בחירת הנושאים) |
| 🗂️ סילבוס | כל החומר של 5 יח״ל במתמטיקה ובפיזיקה (כיתות י׳–י״ב), עם סימון של "למדנו" ו"לומדים עכשיו" |

**כתיבה:** מקלדת (עם שורת סימנים: √ ² π ≤ ≠ θ Δ…) ו-**Apple Pencil**: משטח משבצות שמגיב ללחץ העט, עם צבעים, מחק, ביטול וכפתור "עט בלבד" שמונע מכף היד לכתוב. הכתב נשלח למורה כתמונה, והוא קורא אותו.
נוסחאות מוצגות כמו בספר (KaTeX), וכל הממשק בעברית ומימין לשמאל.

## התקנה – חינם (Gemini + GitHub Pages)

1. **פרסום האתר (פעם אחת):** ב-GitHub נכנסים ל-repo ← *Settings ← Pages*, ובשדה *Source* בוחרים **GitHub Actions**. בכל פעם שמעדכנים את ענף `main`, האתר מתעדכן אוטומטית בכתובת `https://<שם-המשתמש>.github.io/<שם-ה-repo>/`.
2. **מפתח Gemini חינמי:** נכנסים ל-[aistudio.google.com/apikey](https://aistudio.google.com/apikey) עם חשבון גוגל של ההורה, לוחצים *Create API key* ומעתיקים.
3. **באייפד ובאייפון:** פותחים את כתובת האתר ב-Safari ← שיתוף ⬆︎ ← **"הוספה למסך הבית"**. בהגדרות ⚙︎ מדביקים את המפתח ולוחצים **"בדיקת חיבור"**. האפליקציה בוחרת לבד את המודל החינמי הטוב ביותר שזמין.
4. **סילבוס:** במסך 🗂️ "הסילבוס" מסמנים מה כבר נלמד ומה לומדים עכשיו. המורה, התרגולים והמבחנים יעבדו רק על הנושאים שסומנו.

**לגבי המסלול החינמי של Gemini:** יש מגבלה של מספר בקשות לדקה וליום. כשמודל אחד מגיע למגבלה, האפליקציה עוברת אוטומטית למודל אחר. המפתח נשמר רק במכשיר. לפי תנאי המסלול החינמי, גוגל רשאית להשתמש בתוכן כדי לשפר את המודלים, ולכן לא שולחים דרכו פרטים אישיים.

### אופציונלי: Claude (בתשלום, איכות גבוהה יותר)

אפשר להתקין את האתר ב-Netlify (ההגדרות כבר ב-`netlify.toml`). במשתני הסביבה מגדירים `ANTHROPIC_API_KEY` ו-`TUTOR_ACCESS_CODE`, ואחר כך באפליקציה בוחרים ⚙︎ ← ספק ← Claude.

## הרצה מקומית (למפתחים)

```bash
npm install
node server.mjs   # http://localhost:8888  (ל-Claude: ANTHROPIC_API_KEY=... node server.mjs)
```

## מבנה הקוד

- `public/` – האפליקציה עצמה (HTML/CSS/JS, בלי שלב build). אפשר להתקין אותה כ-PWA.
  - `js/pad.js` – משטח הכתיבה לעט. `js/composer.js` – תיבת התשובה (טקסט, עט ותמונה).
  - `js/views/` – המסכים. `js/store.js` – שמירת ההתקדמות במכשיר.
- `public/js/curriculum.js` – **הסילבוס המלא. כאן מעדכנים נושאים לפי פריסת החומר של בית הספר.**
- `public/js/prompts.js` – ההנחיות למורה בכל מצב (סגנון, רמה, פורמט).
- `public/js/api.js` – החיבור ל-Gemini (ישירות מהמכשיר) או לשרת Claude.
- `netlify/functions/tutor.mjs` – שרת אופציונלי ל-Claude. המפתח נשאר בשרת.
- `.github/workflows/pages.yml` – פרסום אוטומטי ל-GitHub Pages.

## הערות

- ההתקדמות נשמרת רק במכשיר שעליו עובדים (אפשר לייצא גיבוי מההגדרות).
- הסילבוס נכתב לפי תוכניות 5 יח״ל של משרד החינוך ([מתמטיקה](https://meyda.education.gov.il/files/Pop/0files/matmatika/Chativa-Elyona/new-curriculum/5-units.pdf), [פיזיקה](https://pop.education.gov.il/tchumey_daat/physics/high-school/pedagogy/curriculum/)). הסדר בכיתה מדעית יכול להיות שונה, וכדאי להתאים אותו לפריסת החומר של המורה.
